# Референсы: как устроены сайты

Источники: [Грильница Красноярск](https://krasnoyarsk.grilnica.ru/), [Magic Burger](https://magic-burger.ru/), [Chicken Dener](https://chickendener.ru/).

Цель — не копировать дизайн один в один, а понять **поток заказа** и **паттерны каталога** для kldfood (доставка + самовывоз + выбор точки + R-Keeper + ЮKassa).

---

## Общая модель

Все три — **классический food e-commerce**:

1. Пользователь выбирает **контекст** (город, точка, иногда только самовывоз).
2. Листает **меню по категориям** (якоря / табы).
3. В карточке блюда — **варианты** (размер, объём, добавки) и цена.
4. **Корзина** всегда на виду (сайдбар / нижняя панель / счётчик).
5. **Checkout**: контакты, адрес или «заберу сам», время, оплата.
6. На сетевых проектах часто **мобильное приложение** как основной канал; сайт дублирует меню.

Для kldfood это ложится так:

| Шаг UI | Бэкенд |
|--------|--------|
| Точка + delivery/pickup | `locations`, `rkeeper_object_id`, флаги delivery/pickup |
| Меню | Каталог (пока mock → БД / синк RK) |
| Корзина | Клиент + валидация на `POST /orders` |
| Оплата | ЮKassa redirect + webhook |
| Кухня | R-Keeper `new_order_delivery` / самовывоз (уточнить taskType) |

## grilnica.ru (Грильница)

**Тип:** федеральная сеть, поддомены по городам (`krasnoyarsk.grilnica.ru`).

**Навигация меню:** крупные категории — Комбо, Шаурма, Пицца, Фри, Вок, «Просто поесть», Напитки.

**Корзина:**

- Пустое состояние с CTA: «Корзина пуста! Добавьте вкусняшку из меню» + сумма 0 ₽ + «Перейти в меню».
- Постоянный блок корзины (не отдельная страница как единственный вариант).

**Мульти-точечность:** в оферте — список ресторанов, адреса на сайте; заказ привязан к ресторану изготовления.

**Приложение:** активный пуш «Попробуйте наше мобильное приложение».

**Вывод для kldfood:** сетевой сценарий = **выбор точки/города до меню**; сильная **sticky-корзина**; категории как главный UX-элемент.

## magic-burger.ru

**Тип:** доставка в городе (Красноярск), богатый каталог.

**Поиск:** поле «Найти блюдо» — ожидание фильтрации по названию/ингредиентам.

**Карточки:**

- Фото-блок, название, **вес**, цена (**«от X ₽»** если варианты).
- **Рейтинг** на карточке (8–10) — социальное доказательство.
- Скидки: зачёркнутая старая цена + новая (комбо, акции).

**Категории:** Новинки, Бургеры, «Блюдо месяца», Шаурма, Дёнер, Снеки, Наборы, напитки, соусы, добавки.

**Фильтры внутри категории:** чипы по типу белка (Курица, Говядина, Сыр…) — быстрый отбор без ухода со страницы.

**Вывод для kldfood:** закладываем **variantGroups**, **priceFrom**, опционально **tags/filters**; блок **новинки/хиты**; поиск на клиенте или через API.

## chickendener.ru

**Тип:** шаурма/дёнер, упор на **самовывоз** (явная плашка: заказы only pickup, часы 9:00–24:00).

**Варианты размера:** МИНИ / СТАНДАРТ / МЕГА на одном SKU — разная цена и граммовка.

**Конструктор:** отдельный сценарий «собери сам» — пошаговое добавление ингредиентов с доплатой за каждый (+₽ / граммы), итоговая цена и вес.

**Сеть:** «45 точек» — критичен **выбор филиала** перед заказом.

**Корзина:** юмористическое empty state («ваша корзина капуста»).

**Вывод для kldfood:** режим **только самовывоз** на уровне сайта или точки; **конструктор** = отдельный тип продукта (modifiers); **restrictions по времени** (workHours / schedule).

## Сводка паттернов для нашего каркаса

| Паттерн | Где видно | У нас сейчас |
|---------|-----------|--------------|
| Выбор точки | Dener, Grilnica | `/location`, `GET /api/locations` |
| Delivery / pickup | все три | `fulfillment` в сессии и заказе |
| Категории + карточки | все | `/menu`, mock menu |
| Размеры / объём | Dener, Magic | `variantGroups` в mock |
| Sticky корзина | Grilnica, Magic | страница `/cart` (UI позже) |
| Поиск | Magic | не реализован — этап вёрстки |
| Конструктор | Dener | не реализован — отдельная фича |
| Рейтинги / акции | Magic | поля заложены в типах mock |
| Оплата онлайн | подразумевается | ЮKassa stub |
| Кухня | — | R-Keeper stub после webhook |

## Предлагаемый пользовательский поток kldfood

```
Старт → [Доставка | Самовывоз] → Выбор точки → Меню (категории)
  → Карточка (варианты) → Корзина → Checkout (контакты, адрес*, время)
  → ЮKassa → Success → (webhook) → R-Keeper → callback статуса
```

\* адрес только для delivery.

Этот поток уже отражён в `apps/web` (без визуального слоя).
